## Technical contract
- Independent layers: base body, skin tone/palette, eyes/face, back/front hair, top/bottom outfit, shoes, gloves, headwear, scarf/cape, backpack, accessories, held Aevin, mount rear/front, effects and shadow. Compatible body presets may share assets. Same direction/frame/pose ID, timing and coordinate/pivot convention; draw order per direction/state. Use matching pose frames or verified deformation, not arbitrary static clothing overlays.
- Direction order S, SW, W, NW, N, NE, E, SE. Mirror only if asymmetrical details/anchors remain correct. 32px tile / 64px trainer canvas proposed; expandable for larger poses, stable feet pivot. 48–64px small Kin and 96–256px mount candidate; test scale.
- P0 states idle, walk, run, turn, interact, hurt, faint, recover, bond_prepare, bond_activate, bond_success, bond_fail. P1 mount_enter/exit, ride_idle/walk/run/turn, swim_idle/move, water_ride_idle/move, fly_idle/move/takeoff/landing. P2 sit, sleep, fishing, wave, happy, laugh, angry, surprised, sad, dance, give_gift. Eight directions supported; document legitimate reuse. Idle 4, walk 6, run 6–8, hurt 3–4, faint/recover 5–6, bond 6–10, ride/swim/fly 6–8 frames are candidate counts.
- Rider and mount sprites independent. Per-frame/direction saddle_anchor, rider_anchor, rider_offset, rider_scale, mount_direction, animation_sync, front/rear occlusion, shadow_anchor, collision_bounds. Reuse neutral ride pose across compatible mounts with overrides. Outfit persists while riding/swimming/flying. Never imply every new garment fits every pose without coverage validation.
- Bond: eligible KO Kin -> target -> Aevin activation in hand -> resonance -> success/fail. No throwing ball. hand_item_anchor; independent prop, rune and particles. Faint: lose balance, collapse, lie, recover; every layer follows pose, no gore.
- Lossless WebP or PNG for transparent pixel atlases; no lossy sprite compression. Nearest-neighbor. JSON metadata, stable IDs independent of filenames. Concept WebP Q88, SVG vector icons. Preserve source masters.
