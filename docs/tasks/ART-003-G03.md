## How separation works
`tools/asset-pipeline/separate_layers.py`
- `label`: writes a label map per sprite to `assets/characters/trainer/labels/trainer_{m,f}_{dir}_labels.png`. Each map is a 64x96 indexed PNG with one palette index per layer. Existing maps are never overwritten unless you pass `--force`.
- `split`: cuts each approved sprite by its label map into per-layer sprites, packs one 8-direction atlas per layer and gender (lossless WebP, `assets/characters/trainer/layers_v3/`), writes `assets/characters/trainer/metadata/trainer_v3_layers.json`, and checks that recombining the layers in render order reproduces the approved sprite exactly. It also writes a colour-coded review image, `build/asset-pipeline/qa/gate03/labels_overlay_3x.png`.

   - every opaque sprite pixel gets exactly one label; transparent pixels get index 0;
