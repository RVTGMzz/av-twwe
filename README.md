# Aevoria — A World Without End

**Project AV-TWWE | Pre-production | Design baseline 0.2**

Original offline, mobile-first creature-taming action RPG. A living fantasy world, real-time companion combat, exploration, social relationships and episodic story expansions.

**Every Kin Matters.** A common companion can remain viable at endgame with more training and investment; rarity offers an early advantage and distinct play styles, not permanent supremacy.

## Project documentation

- [Design baseline](docs/design.md) — gameplay, world, narrative, identity and scope.
- [Combat and balance](docs/balance.md) — manual combat, capture and progression rules.
- [Aspect System 1.0](docs/aspects.md) — approved rules, complete matchup matrix and editable glyphs.
- [Development roadmap](docs/roadmap.md) — prototype gates and repository conventions.

The project is in pre-production. No playable build yet; initial editable UI glyph concepts are available. Proposed terminology and numerical values are not final. All production characters, art, skills, sounds, code and lore must be original or appropriately licensed. No third-party game assets are included.

Repository code name: av-twwe. Public repository: do not commit secrets, personal save files or unlicensed material. No paid infrastructure is required for the initial offline prototype.
